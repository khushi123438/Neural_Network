# Neural Networks

A collection of practical implementations of **Artificial Neural Networks (ANN), Convolutional Neural Networks (CNN), and Recurrent Neural Networks (RNN)** using Python, TensorFlow/Keras, and Jupyter Notebook.

This repository contains different neural network implementations for **classification, regression, image classification, and sentiment analysis**.

---

## 📂 Contents

### 🧠 ANN Classification

**File:** `ANN_Classification.ipynb`

Implementation of an Artificial Neural Network for solving classification problems.

**Dataset:**
- Date Fruit Dataset

**Concepts covered:**
- Data preprocessing
- Feature scaling
- ANN architecture
- Activation functions
- Forward propagation
- Backpropagation
- Model training
- Classification evaluation

---

### 📈 ANN Regression

**File:** `ANN_Regression.ipynb`

Implementation of an Artificial Neural Network for regression problems.

**Dataset:**
- Power Plant Dataset

**Concepts covered:**
- Data preprocessing
- Feature scaling
- ANN architecture
- Regression output layer
- Model training
- Loss calculation
- Model evaluation

---

### 🖼️ CNN for CIFAR-10

**File:** `CNN_for_CIFAR10.ipynb`

Implementation of a Convolutional Neural Network for image classification using the **CIFAR-10 dataset**.

**Concepts covered:**
- Image preprocessing
- Convolution layers
- Pooling layers
- Flattening
- Dense layers
- CNN model training
- Image classification
- Model evaluation

---

### 💬 RNN for Sentiment Analysis

**File:** `RNN_for_sentimentanalysis.ipynb`

Implementation of a Recurrent Neural Network for **sentiment analysis** using the IMDB movie review dataset.

**Dataset:**
- IMDB Dataset

**Concepts covered:**
- Text preprocessing
- Tokenization
- Sequence representation
- Padding
- Embedding
- RNN architecture
- Sentiment classification
- Model training and evaluation

# 🚀 Getting Started

1. Clone the Repository
2. Navigate to the Repository
3. Install Dependencies
``` pip install numpy pandas matplotlib scikit-learn tensorflow keras jupyter ```
4. Start Jupyter Notebook
jupyter notebook

- Open any of the .ipynb files and run the cells sequentially.
